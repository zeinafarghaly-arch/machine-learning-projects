# Machine Learning Projects

A collection of my machine learning and deep learning projects, built using Python, Scikit-learn, TensorFlow, and PyTorch. Each notebook covers a full workflow — from data exploration and preprocessing to model training and evaluation.

## Projects

| Project | Description | Type |
|---|---|---|
| House Prices | Regression models for predicting housing prices | Classic ML |
| Titanic Survival Prediction | Binary classification to predict passenger survival | Classic ML |
| MNIST Digit Classification | Neural network for handwritten digit recognition | Deep Learning |
| Fashion MNIST Classification | CNN-based model for clothing image classification | Deep Learning |
| Arabic Sentiment Analysis | Fine-tuned AraBERT and RNN-family models (LSTM, GRU, BiGRU+Attention) for sentiment classification on Arabic hotel reviews | NLP / Deep Learning |
